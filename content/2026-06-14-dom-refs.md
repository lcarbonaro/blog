# Referencing the DOM

Differences between `getElementsByTagName()` and `querySelectorAll()` including the live vs. static nature of their results, syntax flexibility, and built-in JavaScript loop methods.
## Direct Comparison

| Feature | getElementsByTagName() | querySelectorAll() |
|---|---|---|
| Accepts | Tag name only (e.g., 'div', 'p', 'article') | Any valid CSS selector (e.g., 'div.highlight', '#menu > li') |
| Collection Type | HTMLCollection | NodeList |
| Live vs. Static? | Live. The list automatically updates when the DOM changes. | Static. The list is an unchanging snapshot in time. |
| forEach() Loop? | No. Must convert to an array or use a for loop. | Yes. Built-in forEach method is fully supported. |
| Nodes Included | Contains only Element nodes (HTML tags). | Can contain Elements, comments, or text fragments. |

------------------------------
## Code Examples
## 1. Argument Versatility
`getElementsByTagName()` can only look for literal HTML tag matches. 
`querySelectorAll()` can filter by classes, attributes, and structural nesting:

```js
// Grabs absolutely all list items on the page
const items1 = document.getElementsByTagName('li'); 

// Grabs only checked checkboxes inside a specific form
const items2 = document.querySelectorAll('form#login input[type="checkbox"]:checked'); 

```

## 2. The Live vs. Static Trap
If you manipulate the DOM inside a loop, `getElementsByTagName()` can cause unexpected bugs because its .length updates dynamically as elements are added or removed:

```js
// Assume there are 3 divs on the page
const liveDivs = document.getElementsByTagName('div'); // length: 3
const staticDivs = document.querySelectorAll('div');   // length: 3

// Add a new div to the page
const extraDiv = document.createElement('div');
document.body.appendChild(extraDiv);

console.log(liveDivs.length);   // Outputs: 4 (List auto-updated)
console.log(staticDivs.length); // Outputs: 3 (Snapshot remained intact)

```

## 3. Loop Support out of the box
You can loop over a `querySelectorAll()` result instantly using modern array-like methods:

```js
// WORKS PERFECTLY
document.querySelectorAll('p').forEach(p => p.style.color = 'blue');

// THROWS ERROR: "TypeError: ...forEach is not a function"
document.getElementsByTagName('p').forEach(p => p.style.color = 'blue'); 

// FIX for getElementsByTagName (must spread into a real array first):
[...document.getElementsByTagName('p')].forEach(p => p.style.color = 'blue');

```

------------------------------
## Summary Recommendation

- `querySelectorAll()` is cleaner, accepts complex selectors, supports direct `.forEach()` loops, and avoids the structural traps of live collections. 
- Use `getElementsByTagName()` if you are writing JS targeting older browsers or dealing with a massive DOM where its minor lookup speed advantage is strictly required.
